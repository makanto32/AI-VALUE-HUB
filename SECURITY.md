# Security policy

## Supported versions

Security fixes are provided for the latest stable release. Partners must deploy
immutable release tags and keep application images and infrastructure compatible.

## Reporting a vulnerability

Do not open a public issue. Report suspected vulnerabilities privately to the
repository owner through GitHub Security Advisories. Include the affected version,
impact, reproduction steps and sanitized evidence. Do not include customer data,
credentials, tokens or production endpoints.

The maintainer will acknowledge receipt, coordinate validation and communicate a
remediation or mitigation plan. Partners remain responsible for tenant-specific
identity, network and integration configuration.
