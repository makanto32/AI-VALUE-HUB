# Support

Partners provide first- and second-line support for deployments they operate. Before
escalating, collect the kit version, image digests, Azure region, resource health,
correlation IDs and sanitized logs.

Use a GitHub issue for reproducible documentation or deployment-kit defects that do
not expose customer information. Use a private Security Advisory for vulnerabilities.
Tenant-specific Entra ID, networking, DNS and third-party integration changes are
handled by the partner and customer under their operating agreement.
