# Support

AI Value Hub is a personal, community-maintained project. It is not an official Microsoft product, and it is not covered by Azure or Microsoft support agreements.

## Community support

- Use [GitHub Issues](https://github.com/makanto32/AI-Opportunity-Hub/issues) for reproducible defects and focused feature requests.
- Use [GitHub Discussions](https://github.com/makanto32/AI-Opportunity-Hub/discussions), when enabled, for design and adoption questions.
- Follow [SECURITY.md](SECURITY.md) for vulnerability reports.

Support is provided on a best-effort basis. Include the revision, environment, expected behavior, actual behavior, and minimal reproduction steps. Remove secrets, personal data, tenant details, and customer information.

## Azure services

For issues with Azure services, use the relevant Azure support channel. The repository maintainer cannot provide service-level commitments or support for Azure platform behavior.
